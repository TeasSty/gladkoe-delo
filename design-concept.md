## Niche fingerprint

- Ритуал: запись → вспышки курса → гладкая кожа → абонемент / бонусы UDS
- Материалы: насадка лазера, охлаждающий гель, LPG-роллер, кушетка, одноразовое бельё, флаконы
- Место / свет: кабинеты на пр-те Боголюбова (22А и 39), мягкий клинический дневной свет + тёплая кожа
- Vernacular: «комплекс S/M/L», «зона», «вспышка», «филиал», ироничные слоганы VK
- Сенсорика: короткий щелчок/тепло вспышки → гладкость на ощупь

## Unique thesis

1. Mood: холодный кабинетный свет + тёплая кожа; «гладкое дело» = курс вспышек, не spa-ритуал
2. Type rationale: бренд = их script-лого как hero-signal; UI — humanist sans (Albert Sans / Outfit), без огромного editorial serif, который бьётся с тонким script
3. Palette logic: porcelain white из обложки VK; champagne gold из лого; teal/ink из их промо-карточек; ink для текста — не чужой luxury moodboard
4. Composition: light-gallery-strip — full-bleed hero (кожа + вспышка света) → горизонтальная лента зон/процедур
5. Motion: один мягкий flash на hero, медленный drift ленты, fade секций (2–3 жеста)
6. Main gesture: «лента гладкости» — светлые кадры кожи/аппарата как ритм сайта
